# justintabarini.com

Static bio site, hosted on GitHub Pages.

## Photos
Drop images into `assets/photos/` with these names (empty slots show a soft placeholder until then):

| File | Where it shows |
|---|---|
| `headshot.jpg` | Top of the page, next to the intro (the waterfall photo) |
| `machu-picchu.jpg` | "Off the clock" gallery |
| `tuscany.jpg` | "Off the clock" gallery |
| `concert.jpg` | "Off the clock" gallery |
| `nyc-dinner.jpg` | "Off the clock" gallery |
| `mmt-screenshot.png` | Next to the MMT Tool section |

Resize to about 1200px on the long side before committing.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server 8003`.
